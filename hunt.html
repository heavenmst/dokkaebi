내 기록 비교 — 분당 · 시간당 획득량

계산 방식 · 설명 보기
  • 전래동화는 판이 둘이에요. [주간 비경] = 주 5시간(수요일 05:00 충전) 동안의 드랍표, [상시 비경] = 그 5시간을 다 쓴 뒤의 드랍표. 이름은 같아도 재료 양이 크게 달라요(원님 고개 재료: 주간이 상시의 약 27배). 주간 원님 고개 숫자는 게임 데이터 + 실제 47,000마리 기록으로 확인.
  • 기록마다 사냥터와 실제 분당 처치를 넣으면 게임 데이터 드랍률로 분당·시간당 평균 획득량을 계산해요.
  • 첫 번째 기록 대비 차이를 %로 보여줘요(초록 = 더 많음).
  • 도술 요령서 = 12종(절명~제압) 합계, 원하는 1종은 이 값 ÷ 12. 단이 담긴 상자 = 열면 정기단 1~10개 무작위지만 실제 확률은 1개 21%·2개 50%·3개 25%·5개 3%·10개 1% (게임 데이터) → 1개 = 정기단 평균 2.21개로 환산. 단 합계 = 정기단 + 영기단×4 + 천지단×16 + 조화단×64 + 상자 환산. 강화 비법서 합계 = 장비 강화 비법서(책)를 전설 1장 기준으로 환산: 전설 + 영웅÷10 + 희귀÷100 + 일반÷1000 — 철·옷감·피혁 같은 강화 재료가 아니에요.
  • 강화 재료는 사냥에서 희귀(철광석·옷감·피혁)·영웅(철 주괴·고급 옷감·강화 피혁)만 나오고 전설 재료(연마된 철 주괴 등)는 드랍이 없어요.
  • 영기 수련 가속 = 1분·5분·10분권 드랍률 × 분을 모두 더한 값. 장비 아이템 = 청동 운검·흑암 단도·승려의 지팡이·바람물결 은선·물소뿔 흑각궁·군관의 전립·군관의 구군복·영기 흡수의 단화·청동 다리보호구·영기 흡수의 장갑·영혼술사의 홍색 각대 드랍 확률 합, 1개 = 요혼석 2개로 환산. 요혼석 시세를 넣으면 가치 합계에 들어가요.
  • 만귀령패는 쉬움·보통·어려움이 서로 다른 아이템이라 따로 표시.

같은 양 벌려면 — 다른 사냥터에서 분당 몇 마리

K 몬스터 투력이 이 범위인 단일 비경·필드만 (낙화의 전장 제외) · 화살표로 10K씩 · 전투력 비우면 기준 사냥터 투력 기준
계산 방식 · 설명 보기
  • 이 이상 잡으면 이득 = 왼쪽 「이득 기준」으로 고른 항목을 지금 사냥터만큼 얻으려면 분당 몇 마리 잡아야 하는지. 아이템을 엽전으로 바꾸는 가치 계산은 하지 않아요. 오른쪽 시간당 칸은 모든 사냥터를 지금 분당 처치 수로 잡는다고 보고 게임 데이터 드랍률로 계산(금색 = 이득 기준 항목).
  • 초록 = 지금보다 적게 잡아도 이득 · 노랑 = 비슷 · 빨강 = 더 많이 잡아야 함. 줄을 누르면 아래에 그 사냥터 몬스터가 나와요. 같은 사냥터 안 구역은 몬스터 레벨·전투력이 달라서 나눴어요(세부 지역은 마우스 올리면 보여요).
